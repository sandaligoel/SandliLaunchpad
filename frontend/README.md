# AgentForge UI (frontend)

React + Vite app for Agent Launchpad, workflow builder, and agent library.

## Dev

From repo root:

```bash
./scripts/start-backend.sh
cd frontend && npm run dev
```

Open http://localhost:5173/interview

All `/api/*` and `/health` requests are proxied to the AFFINE FastAPI backend (see `config/runtime-ports.json`).

## Env

- `.env.development` — minimal defaults
- `.env.local` — auto-generated by `./scripts/sync-dev-env.sh` (do not commit)
